# 开源研究与二次设计 / Open-source research

核对日期：2026-09-16。采用组件与设计个人案例是两件事；以下逐项说明实际关系。

| 项目 | 许可核对 | 适用价值 | 本作品集的取舍 |
|---|---|---|---|
| [Motion](https://github.com/motiondivision/motion) | MIT | React 动效、进入/退出与减少动态支持 | 已沿用现有 Framer Motion 依赖。v5 在版式与案例进入中使用，视频跳转另用原生浏览器能力。 |
| [Lenis](https://github.com/darkroomengineering/lenis) | MIT | 连续滚动与页面动效协调 | 研究参考，未新增依赖。保留浏览器原生滚动有利于阅读位置、键盘和历史恢复。 |
| [React Bits](https://github.com/DavidHDev/react-bits) | MIT + Commons Clause；并非无限制 MIT | 交互组件与视觉动效灵感 | 用于研究对照，未复制组件。其许可限制组件本身的出售、转授权或再分发。 |
| [Resume Formatter](https://github.com/gracexygu/resume-formatter) | MIT | 简历编辑与文档工作流基础 | 既有二次开发案例；个人设计贡献围绕母版/岗位版、局部改写审阅与撤销。保留上游来源。 |
| [sen-3d-resume](https://github.com/dayinji/sen-3d-resume) | 代码 MIT，个人与品牌素材另有排除条款 | 原站代码起点 | 保留历史归属。v5 已移除个人三维模块，重新组织视频、案例、内容与交付。 |

本轮选择复用已有、适合任务的基础能力，把改动集中在案例叙事、真实媒体控制、交互状态与文档一致性。没有将参考项目另算作本人原创成果，也没有因追求动效数量而引入第二套滚动控制。

两段网站原视频由作品集作者指定使用，来源与文件指纹见 [媒体来源](media/v5/sources.json)。视频承担开场和联系场景，不属于本人案例成果。

## English

Motion is retained as the existing animation dependency. Lenis and React Bits were evaluated as references, not added or copied. Resume Formatter remains an attributed derivative project. The original sen-3d-resume code foundation is credited; its code license does not license personal or commercial imagery. Portfolio-specific content, layout, video controls and delivery work are distinguished from upstream contributions.
