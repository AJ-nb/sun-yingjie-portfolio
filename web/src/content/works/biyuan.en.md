## Context

A shared identity, clear information hierarchy and continuous task paths for a multi-model service.

## My role

Visual identity, UI design & experience iteration.

## Design problem

How can multiple models and services become an experience people can understand, choose from and continue using?

## Design decisions

### Create a consistent entry point

Align identity, page hierarchy and key actions so users can recognise the service across screens.

![Biyuan desktop homepage](/works/refinement-brand/biyuan/home-desktop.png)

### Make model information comparable

Distinguish the main task, model information and operating state instead of treating all content equally.

![Biyuan model directory](/works/refinement-brand/biyuan/models-desktop.png)

### Carry the experience across screens

Keep a shared reading order on desktop and mobile, then adjust density for screen size and interaction.

![Biyuan mobile homepage](/works/refinement-brand/biyuan/home-mobile.png)

## Outcome & stage

Visual identity and desktop/mobile interface design and iteration, presented within the boundaries of product collaboration and prototyping.

## Reflection

Visual consistency must work with task logic. Model selection, feedback and next actions should reduce the effort of understanding; effects require actual user research.
