## Background

Biyuan AI serves creators and developers using different models. Its website must explain a unified access service and then help visitors find a model, documentation and an entry point. Brand identity therefore includes both a recognizable mark and the sequence from understanding to action.

## My role

I was responsible for overall visual design and supported the launch, working with the team on identity, website visuals, information hierarchy and actions. I translated design directions into concrete pages and supported launch checks and refinement. The underlying service and model capabilities belong to their respective teams.

## Key question

Visitors arrive with different intentions: learning about the service, finding a known model, or reading an API before using it. The homepage and directory need to support exploration and direct lookup without sending everyone through one route.

## Design process

### Use identity to clarify action hierarchy

A dark symbol and Chinese wordmark establish identity, with warm white and orange connecting headings, actions and status. The opening introduces the one-key service alongside Quick Start and API Documentation, supporting use and prior reading.

### Support two ways to search the directory

Use-case filters support exploration, while name search serves a known target. Try and Copy Name connect understanding, selection and later use. A search result demonstrates directory behavior, not a completed live call to every listed model.

### Separate connection checking from creative work

Lensflow and Resume Formatter already include a Biyuan preset. Users configure the service, retrieve account models and check the connection before deciding which images or text to submit. This retrospective describes the existing flow as identity, selection and input confirmation; no conversion data accompanies that interpretation.

## Final work

The website and directory provide public entry points, while tool presets bring the service into concrete creative tasks. Lensflow leaves universal provider compatibility unverified. Resume Formatter retains rewrite review and explains the scope before sending a full document. The connection between brand and product lies in the next available action as well as visual consistency.

## Outcome and stage

The visual experience connects brand identity, the homepage, model directory and tool presets, with support for the public launch. Information hierarchy and distinct entry paths give service exploration, model lookup and documentation a clear next action.

Mobile retains the identity, heading and primary actions, with secondary links below. Public page status, capture date and tool versions are recorded separately; model availability depends on the service and account.
