## 项目目标

把摄影中的布光知识转成生成模型能执行、创作者能检查的短提示词。我的方法是同时写清三件事：光叫什么、从哪里来、脸部或背景应出现什么。

这组个人实验由我负责视觉判断，Codex 辅助组织内容，Image 2.5 生成图像。九张完整图像保留封面与全部对照，不以抽象的“电影感”代替具体观察。

## 基础布光：方向与阴影

### 柔光与硬光

![柔光与硬光对照图](/works/portrait-lighting/02.jpg)

左侧阴影较浅；右侧鼻影和下巴影更明确。参考人物原本偏柔光，因此两张图不能单独隔离参考图的影响。

```text
阴天漫射柔光，天空均匀照亮面部，阴影浅而柔和。室外灰墙背景。
```

```text
晴天直射硬光，太阳从左上方照来，鼻影与下巴影边缘清晰。室外灰墙背景。
```

### 直闪与跳闪

![直闪与跳闪对照图](/works/portrait-lighting/03.jpg)

直闪样例在背景墙留下明显人影，面部反光也更直接；跳闪样例的暗部过渡较柔和。写出白色天花板，让反射路径比一个布光名词更具体。

```text
机顶直闪，正面硬光，人物身后的灰墙留下清晰硬影。
```

```text
跳闪，闪光经白色天花板反射，柔和照亮面部，阴影过渡平缓。中灰背景。
```

### 侧逆光

![侧逆光对照图](/works/portrait-lighting/04.jpg)

发丝和肩部的暖亮边增强了主体与背景的分离；同时保留正面五官，避免脸部只剩暗影。

```text
黄金时刻侧逆光，低角度暖阳从右后方照来，发丝肩缘镀金，面部保留细节。
```

### 顶光

![顶光对照图](/works/portrait-lighting/05.jpg)

眼窝、鼻下和下巴更暗，五官仍可辨。顶光强调造型；如果目标是亲近、明快，应重新考虑这一选择。

```text
顶光，头顶正上方单灯向下照，眼窝与下巴投影加深，保留五官可辨。中灰背景。
```


## 创意布光：位置与范围

### 双色凝胶光

![双色凝胶光对照图](/works/portrait-lighting/06.jpg)

蓝橙首先在两侧头发和脸缘显现，脸中央仍偏中性。画面支持冷暖氛围，但不能将其描述成严格等分的蓝橙半脸。

```text
双色凝胶光，左侧蓝光、右侧橙光，两色分别照亮两侧脸部。中灰背景。
```

### 百叶窗投影

![百叶窗投影对照图](/works/portrait-lighting/07.jpg)

平行明暗条纹落在脸和肩部，检查重点是投影的位置与走向；相同写法也可以组织其他遮挡图案。

```text
百叶窗光，侧上方硬光穿过百叶窗，平行明暗条纹落在脸和肩上。中灰背景。
```

### 聚束光

![聚束光对照图](/works/portrait-lighting/08.jpg)

脸部成为亮度中心，胸口与背景更暗。观察亮区边界是否围绕脸部形成有效集中，而非全局压暗。

```text
聚束光，窄束硬光只照亮脸部，胸口和背景明显变暗。
```


## 描述精度与皮肤质感

### 从光型名称到可检查的结果

![从光型名称到可检查的结果对照图](/works/portrait-lighting/09.jpg)

左图只在光线段写“分割光”，完整输入仍有人物和皮肤要求；右图明确左侧 90 度硬光、右脸深暗与无补光。两者不是严格的单变量实验，但展示了具体方向与结果描述的作用。

```text
分割光。
```

```text
分割光，左侧90度单灯硬光，右半脸深暗，无补光。

参考图只用于同一人物和衣服。正面胸像，灰底，3:4。保留真实皮肤纹理，T区反光随光源自然变化。
```

图中雀斑大多仍在，鼻梁和额头会随光变亮，但细小肤纹仍偏光洁。看见雀斑并不等于毛孔与微纹理已经完全真实；T 区也不必一律压成哑光。

以下降噪补句保留为待试建议；这组图没有对它做独立前后对照。

```text
干净数码成像，减少可见噪点，保留皮肤细纹。
```

## 可复用提示词与迭代

将光型、方向和一个可见结果写成短句；背景确有要求时再补充背景。生成后先寻找指定结果，没有出现就修改对应句子。

```text
[光型]，光从[方向]来，[脸部／背景／发丝出现一个可见结果]。[背景]。

真实皮肤纹理，T区反光随光源自然变化。
```

完整输入示例：

```text
晴天直射硬光，太阳从左上方照来，鼻影与下巴影边缘清晰。室外灰墙背景。

参考图只用于同一人物和衣服。胸上肖像，3:4。保留真实皮肤纹理，T区反光随光源自然变化。
```

换人物、背景或生成环境时重新检查鼻影、墙影、发丝亮边与肤纹；逐项调整，保留上一版本用于比较。

## 成果与应用

项目形成九张图像、一组短提示词与一套观察方法。核心收获是把抽象光型转成画面中的位置和明暗关系，让下一轮修改有具体目标。

这些比较展示当前样例的表现，不推导模型的普遍成功率。将它用于[角色卡设计](/work/character-consistency)时，应区分光照变化与人物结构变化；用于[水墨影像](/work/ink-realm)时，可继续检查连续镜头中的主光方向。
