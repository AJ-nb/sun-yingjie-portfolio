# 本轮技能与工具的实际使用

本轮沿已确认的实施方案完成改造，技能用于设计判断、制作与验证，没有把“已安装”列为“已完成”。

| 技能 / 能力 | 实际用途 |
| --- | --- |
| web-design-engineer（含 redesign-protocol、browser-acceptance） | 现状梳理、视觉方向、实现与浏览器验收 |
| frontend-design（含中文排版参考） | 展览式章节、暖白案例阅读面、中英文排版与响应式布局 |
| emil-design-eng | 控件反馈、键盘操作、焦点和低动态设置 |
| apple-design | 流体交互与动效克制；本轮参数由项目决定，不宣称是 Apple 官方数值 |
| GitHub | 源码读取、开源机制与许可核查、版本提交与交付 |
| imagegen | 两次对原始 HUHU 图进行保形编辑尝试；服务返回上传解析错误，未产生新图 |
| Documents / PDF | 精选与完整作品集、Word 简历、PDF 导出及版面检查 |
| 浏览器控制、Playwright、axe | 人工查看与生产构建上的路由、键盘、触摸、图片、视频、下载和可访问性验证 |

Product Design 的路由与审阅能力经过适用性评估；没有用历史截图冒充新站点的实际产品审阅。Figma、Canva、额外滚动或动画库未为增加工具数量而引入。开源研究范围与最终采用项见 [研究记录](open-source-research-v3.md)。

实际测试结果以浏览器和文档 QA 记录为准，使用某项技能本身不代表验证通过。
