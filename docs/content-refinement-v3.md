# Case content refinement v3

Date: 2026-09-15. Scope: all 33 existing cases, in Chinese and English (66 Markdown files).

## What changed

Eight priority cases were rewritten across all six existing sections. Each now has three specific design-decision headings within the design-process section. The narrative connects a problem to visible or documented evidence, explains a judgment, and states the achieved stage. New retrospective readings and next-step recommendations are identified as such; they are not presented as previously conducted research.

The other 25 cases received focused revisions to their key question and process. Existing refinement-v2 appendices were integrated where they repeated the main story. XHS method research now separates the underlying editing experiment, method diagram and foundation implementation. Long source-board, alternate-render and earlier-version groups use native disclosure elements, while main evidence remains directly visible.

All frontmatter remains unchanged: title, summary, category, role, credits, status, cover and tags. All six level-two section names remain unchanged in each language. Existing image references, captions, original credits, external project entry links and source records are retained; no third-party project has been relabeled as a new personal accomplishment.
