# v4 实际使用的技能与工具

| 技能 / 工具 | 本轮用途 | 边界 |
| --- | --- | --- |
| web-design-engineer / redesign-protocol | 重构信息层级、定义黑/荧光黄绿/纸白系统，建立先作品后完整履历的展示顺序 | 用户已明确授权全面实施并同步仓库，直接在既有产品上完成可审查实现 |
| emil-design-eng | 可逆选择、触控等价入口、减少动态效果、暂停、焦点和阅读上下文恢复 | 不将使用技能本身视为体验验证 |
| github / GitHub CLI | 10 个方向重新检索、源码/许可核查、版本同步与远端 CI | 119 个搜索候选、29 个重点源码；不是扫描全部 GitHub |
| imagegen | 对原始 HUHU 图尝试保形透明背景处理 | HTTP 500 / convert_request_failed，无新图可用；未调用需要另行明确选择的 CLI/API 回退路径 |
| Playwright / axe / 浏览器预览 | 真实生产构建上的桌面/手机/双语/触控/键盘、历史状态及视觉检查 | 自动检查不是完整 WCAG 认证，不把本地性能样本描述为用户实测 |
| 并行子任务 | 个人内容与证据、开源和逻辑研究、独立代码审查、浏览器回归 | 主任务整合实现、修复发现的问题并核对交付状态 |

原透明数字人像的 alpha 直接用于网页分层。半透明顶栏、图像与图形叠层属于界面呈现，不是新照片或新产品渲染。本轮没有新增通用动效依赖，也没有为工具数量安装无关插件。
