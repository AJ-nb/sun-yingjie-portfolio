# 设计如何形成 · 第三轮实现

本轮保持三维人物、六章展览、33 个案例与中英文独立地址，深化「品牌与产品设计＋AI」定位。页面把作品、设计判断和可操作的固定样本放在同一条阅读路径上。

## 视觉与交互

- 人物首屏以鼠尾草绿、砂色和深绿组织，姓名与简介改为左侧编排。沿用原创 GLB 的形体、眼球与镜头轨迹，降低均匀补光，建立暖主光、冷补光与轮廓光；去除泛光并减轻景深，保留材质边缘。它仍是风格化人物，并非照片或扫描。
- 六章各有一个具体的设计问题，连接封面和项目列表。桌面保留横向章节；手机和低动态设置切换纵向排列。首页始终提供完整目录直达。
- 案例使用暖白阅读面、六段目录、图片来源标签、原稿展开区，以及按设计问题关联的后续案例。大图支持缩放、键盘切换、触摸与关闭后的焦点恢复。
- 中英文字体本地托管：Noto Sans SC 根据当前内容提取 400/600 字重子集，Bodoni Moda 用于拉丁展示文字。修改正文后可执行 `python scripts/subset_fonts.py`；字体许可随发布资源提供。
- 页面进入用 280ms 的轻微位移和淡入；标题不再进行模糊和字距重排。路由直接挂载目标内容，防止异步模块阻塞退出导致 URL 和正文不一致。

## 八个固定样本实验

| 案例 | 操作 | 证据边界 |
| --- | --- | --- |
| Hermès | 切换季节和构图热点 | 使用原项目图片，回顾画面组织 |
| 铝型材灯具 | 切换四种灯型 | 讨论共同截面与构成，不推定量产 |
| 引渡者 | 扫描、清理、返回与爆炸图热点 | 固定流程讲解，不是控制或仿真系统 |
| HUHU CARE | 儿童、家长、医护视角 | 概念研究，不输出诊断或临床结论 |
| 彼源 | 原界面图引导路径 | 既有页面截图，无实时服务或账号 |
| Periastra | 原稿负形、尺寸和反相检查 | 原标志图裁切，未冒充新增品牌成果 |
| Lensflow | 局部失败与重试 | 本地固定任务，仅重试失败项，保留成功项 |
| 简历编辑器 | 接受、拒绝、撤销 | 本地样例，不读取访客文件或调用模型 |

这些实验是本轮新增的作品讲解，不回填为项目当年的用户测试或商业成绩。开源代码与设计参考的来源、许可和实际采用范围见 [研究记录](open-source-research-v3.md)。

## 图像与性能取舍

图像增强服务在两次参考图编辑中均返回 HTTP 500 / `convert_request_failed` / `failed to parse multipart form`，没有产生可审阅图片。因此本轮没有发布新生成图，也没有把新背景或光照当作实物照片。原始项目图保持不变，真实感优化发生在实时人物光照、清晰度、作品选择和阅读呈现层面。

检查过 glTF Transform 的无损去重：模型约 10.21MB → 10.20MB，收益很小，因此没有替换原始 GLB。Validator 返回 0 错误、0 警告；七个空焦点节点是镜头锚点，必须保留。新增校验锁定镜头动画、焦点和眼球根节点。

三维在延迟后加载，低动态模式需主动开启，画布离屏或页面隐藏时暂停。所有原图只在对应案例中按需加载，大图预加载相邻一张，案例实验和查看器分包加载。

## 文档

精选版 28 页、8 个深入案例；完整版 116 页、33 个案例；简历为一页 PDF 与可编辑 Word。精选、完整和简历下载有独立路径。详细质量记录以 `docs/document-refinement-v3.md` 和各交付目录内 manifest 为准。

`web/dist` 仅包含案例、实验、下载和许可证的明确允许资源；私人原件不进入网站构建。GitHub 默认分支更新与托管站点发布是不同状态，交付记录分别报告。
