# 第三轮交付：设计如何形成

本轮完成网站与文档的第三版改造，保留原有三维人物、六章结构、33 个双语案例和项目来源。当前代码版本为 0.3.0。GitHub 交付使用 `portfolio-design-v3` 分支向默认分支 `portfolio-redesign` 提交合并请求；具体提交与合并状态以仓库记录为准。

## 实现内容

- 鼠尾草绿、砂色与深绿的人物首屏；暖白案例阅读页、展示字体、六章设计问题与响应式作品目录。
- 全部 66 篇双语正文精修；八个重点案例加入固定样本交互，并保留署名、阶段和原图。
- 全屏图片缩放、键盘与触摸操作、来源图注、六段阅读目录、关联案例、原稿展开区。
- 返回时恢复筛选、阅读位置和焦点；延迟加载、低动态模式、三维失败与低性能回退。
- 精选、完整作品集与简历独立下载；源码、许可文本和当前内容共同维护。

## 范围与限制

对70个GitHub候选进行检索，其中35个重点仓库完成机制与许可核查。实际采用、参考和未采用项分别记录于 [开源研究](open-source-research-v3.md)。216个包的许可或原声明随仓库与网站构建保留；第三方作品没有被改写为本人的项目经历。

两次参考图编辑均因图片服务的 multipart 解析错误失败，未得到可审阅的新图。本轮改善现有三维人物的主光、补光、轮廓与清晰度，原始作品图保持原身份；不能称作已经完成整组 AI 修图或照片重拍。

GitHub 更新与 Sites 托管发布分开记录。本轮没有更改仓库可见性，也没有把原受限站点开放给公众；历史站点版本与访问状态见 [第二轮交付](DELIVERY.md)。
