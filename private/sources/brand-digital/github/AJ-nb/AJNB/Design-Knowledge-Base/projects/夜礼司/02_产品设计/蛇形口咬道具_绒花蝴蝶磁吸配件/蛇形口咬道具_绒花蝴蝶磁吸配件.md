# 蛇形口咬道具_绒花蝴蝶磁吸配件

## 当前归属

该产品研究当前归属品牌为 **夜礼司**。`Songnasty` 保留为早期研发阶段名称，用于记录产品方向如何积累到当前品牌系统。

## 项目概述

这是一款用于私密摄影的人体佩戴式视觉道具。产品由两部分组成：

1. 蛇形口咬主体
2. 绒花蓝色闪蝶磁吸配件

用户通过口部咬住蛇尾，蛇头朝向外部。蛇头口腔内部嵌入磁铁，蝴蝶腹部同样嵌入磁铁，两者通过磁吸方式连接。佩戴后，蝴蝶停留在嘴部前方，形成遮挡、封口、凝视与欲望隐喻。

## 概念摘要

这套设计的价值不在“蛇 + 蝴蝶”的表面组合，而在于它建立了完整关系链：

- 蛇：危险、欲望、控制、缠绕
- 蝴蝶：柔美、脆弱、诱惑、被观看
- 磁吸：隐藏的连接机制
- 口咬：身体参与方式
- 嘴部遮挡：沉默、克制、封存欲望

最终叙事链条是：

**人 → 咬住蛇 → 蛇捕获蝴蝶 → 蝴蝶遮住嘴**

## 与夜礼司品牌的关系

夜礼司的品牌方向不是直接露骨，而是将亲密表达转译为被仪式化、被结构化、被授权的视觉系统。这件产品与夜礼司 Logo 的底层逻辑一致：

- 都强调秩序中的身体感
- 都强调被确认、被控制、被保护的私密表达
- 都避免简单低俗的直接刺激

## 结构逻辑

- 蛇头张口区域承担磁吸安装位置
- 蛇身曲线同时承担生物感与绳索感
- 尾端承担人体工学咬合功能
- 蝴蝶腹部承担连接节点
- 绒花材质中和攻击性，使产品从普通成人道具转向身体装置与拍摄饰品

## 工艺与安全

- 蛇头应继续去玩具化，向饰品化、雕塑化推进
- 咬合尾端需要食品级或医用级安全材料方案
- 磁铁必须完全包覆，不能裸露
- 蝴蝶尺寸建议继续做 S / M / L 级别测试
