# Periastra 应用与优化

## 核心结论

Periastra 这条线的问题不是方向错，而是要把已经成立的 `P + 镜头旋涡 + 保护容器` 结构，进一步压到能落在真实器材、五金和包袋工艺上的程度。

## 优化优先级

### 1. 先稳住首字母识别

- 左侧主干要更明确
- 中央圆腹比例要更像 `P`
- 旋涡感不能强到压过首字母入口

### 2. 再减轻中心拥挤感

- 扩大中央负形
- 减少交叠黑色堆积
- 让镜头聚焦感更清楚，不只是更复杂

### 3. 统一线宽系统

- 外框、主干、内部旋涡不能完全同粗
- 主识别结构更稳
- 内部旋涡略轻
- 缩小后不糊成一团

### 4. 把断口做成设计逻辑

- 顶部断口像旋涡入口
- 右下断口像旋转出口或结构切口
- 节奏要一致，不能像没画完

## 应用端要验证什么

### 产品应用

- 金属铭牌
- 拉链头浮雕
- 肩带织唛
- 内胆隔板压印
- 包装封签
- 防尘袋丝印
- 镜头收纳袋标签

### 工艺关注点

- 小尺寸下负形是否仍清楚
- 压印后内部是否堵死
- 金属件上边界是否仍干净
- 黑白反转后是否仍有识别力

### 必测尺寸

- 16px 数字图标
- 8mm 五金标
- 20mm 织唛
- 30mm 橡胶章
- 包身主标尺寸
