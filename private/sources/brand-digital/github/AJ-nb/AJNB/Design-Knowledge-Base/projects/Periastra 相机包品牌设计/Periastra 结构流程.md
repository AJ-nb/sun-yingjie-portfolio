# Periastra 结构流程

## 结论

Periastra 不是把 P 做复杂，而是把字母识别、镜头联想和保护结构压进同一个器材符号里。

```mermaid
flowchart TD
    A[P] --> B[竖向主干]
    A --> C[弧线腹部]
    B --> D[保护外框]
    C --> E[旋涡与聚焦]
    D --> F[容器感]
    E --> G[镜头联想]
    F --> H[相机包属性]
    G --> H
    H --> I[最终标志]
```
