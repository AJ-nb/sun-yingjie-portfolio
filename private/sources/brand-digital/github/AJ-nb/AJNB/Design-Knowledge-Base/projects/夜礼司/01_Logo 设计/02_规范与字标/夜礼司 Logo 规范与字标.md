# 夜礼司 Logo 规范与字标（基于 Songnasty 历史研究升级）

## 当前基准图

![夜礼司最终Logo](<../assets/logo/yelisi-final-logo-v01-20260514.png>)

## 当前系统定义

夜礼司的 Logo 系统以图形标为核心，中文字标“夜礼司”为主识别，`YELISI` 和 `Night Ritual Atelier` 作为辅助英文系统存在。

历史上的 `Songnasty` 中英字标研究不删除，但只作为字标系统演化的前期资料，不再作为现行规范。

## 1. 结构层级

### 一级识别
- 印面外框
- 内部篆意结构
- 中央负形身体曲线

### 二级识别
- 中文字标“夜礼司”

### 三级辅助
- `YELISI`
- `Night Ritual Atelier`

## 2. 字标原则

### 中文字标
- 细而挺
- 横竖秩序清晰
- 具有现代篆意
- 字间距偏大，形成仪式感
- 不做过度毛笔化处理

### 英文辅助
- `YELISI` 作为音译标识
- `Night Ritual Atelier` 作为品牌气质翻译
- 英文应弱于中文，不应与图形争主识别

## 3. 应用场景

### 推荐
- 产品包装正面主标
- 礼盒封签
- 铭牌与吊牌
- 产品压印
- 烫金 / 烫黑
- 说明书封面
- 数字头像与 favicon

### 不推荐
- 彩色渐变填充
- 复杂肌理覆盖图形主体
- 过小尺寸强行加入完整英文副标题
- 拉伸、压扁或随意改变断口比例

## 4. 工艺建议

| 工艺 | 适配程度 | 说明 |
|---|---|---|
| 黑色丝印 | 高 | 包装与说明书基础方案 |
| 无色压印 | 高 | 最适合强化私印感 |
| 烫金 | 高 | 礼盒和限定版本优先 |
| 烫黑 | 高 | 与威严气质更一致 |
| 金属蚀刻 | 高 | 适合铭牌与配件 |
| 激光雕刻 | 中高 | 适合皮革、木质、金属 |
| 彩色渐变 | 低 | 会削弱权柄感 |
| 纹理填充 | 低 | 破坏识别稳定性 |

## 5. 尺寸与留白

### 最小尺寸
- 数字头像：`64 × 64 px` 以上
- 包装小标：`12 mm × 12 mm` 以上
- 压印版本：`18 mm × 18 mm` 以上
- 烫金版本：`15 mm × 15 mm` 以上
- 横向组合宽度：`45 mm` 以上

### 留白
以图形外框厚度为 `X`：

- 四周最小留白：`2X`
- 图形与中文字标间距：`1.5X–2X`
- 图形与英文辅助系统间距：`2X–3X`
