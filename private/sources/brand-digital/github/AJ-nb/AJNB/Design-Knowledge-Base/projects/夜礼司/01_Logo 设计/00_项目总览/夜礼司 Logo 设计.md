# 夜礼司 Logo 设计（原工作名：Songnasty）

## 当前定义

当前正式 Logo 已从 `Songnasty` 早期的英文识别逻辑，转向 `夜礼司` 的中文语义与印面结构逻辑。

这条线的目标不是普通女性品牌图标，而是一枚具有私印感、秩序感、权柄感与隐性身体气韵的现代品牌印记。

这个 Logo 当前成立，不是因为“像印章”，而是因为它同时完成了四件事：

1. 以近方形印面建立外部秩序
2. 以内部分布接入篆书的稳定空间逻辑
3. 以中央负形隐藏女性身体曲线
4. 让第一识别层是威严与制度感，第二识别层才是身体与亲密感

## 历史与现行的边界

历史积累保留，但必须分清角色：

- `Songnasty` 阶段：研究英文名、S 曲线、反差性感的视觉可能性
- `夜礼司` 阶段：建立中文语义、私印秩序和被授权的私密品牌印记

旧研究不删除，但不能继续主导现行方向。
