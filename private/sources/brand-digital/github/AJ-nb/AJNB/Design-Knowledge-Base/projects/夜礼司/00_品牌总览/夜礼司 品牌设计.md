# 夜礼司 品牌设计（原工作名：Songnasty）

## 当前定义

`夜礼司` 是当前正式采用的品牌名称。`Songnasty` 保留为历史工作名，用于记录早期品牌探索、图形试错和方向迁移。

这不是简单改名，而是品牌结构重心改变：

- `Songnasty` 阶段更偏英文名、时装化反差、S 曲线识别
- `夜礼司` 阶段更偏中文主导、私印秩序、篆书空间和被压低到第二识别层的身体感

## 当前品牌结论

夜礼司的品牌核心不是直接表现情欲，而是通过 `夜 / 礼 / 司` 三层语义建立：

- 夜：私密场域
- 礼：秩序与边界
- 司：权柄与确认

因此，品牌的最终视觉方向不是轻浮性感，而是：

- 威严
- 私密
- 仪式感
- 身体主权
- 克制的亲密表达
