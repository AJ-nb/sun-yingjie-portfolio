# 蛇形口咬道具 结构与叙事流程

## 结论

这件产品不是蛇和蝴蝶的拼贴，而是把口咬、磁吸、遮挡和意象叙事压成一个结构系统。

```mermaid
flowchart TD
    A[蛇尾口咬区] --> B[蛇身支撑]
    B --> C[蛇头磁吸位]
    C --> D[蝴蝶连接点]
    D --> E[嘴前遮挡]
    E --> F[完成佩戴关系]
```

```mermaid
flowchart LR
    A[人咬住蛇尾] --> B[蛇形成牵引关系]
    B --> C[蛇头捕获蝴蝶]
    C --> D[蝴蝶停驻唇前]
    D --> E[沉默 / 封存 / 被观看]
```
